# Scoped Office content checks (T12)

`resolve_text_scope(obj, location, options)` returns text plus actual structured
locations. It never searches outside the requested scope to rescue a failed
match. With no location selector, text.contains retains whole-file search.
Matching remains case-sensitive substring matching, not semantic/visual proof.

Supported scopes:

- Excel: explicit worksheet, single cell or rectangular range. A cell/range
  requires its worksheet. Invalid/reversed/out-of-format ranges are spec gaps;
  a valid but absent worksheet is an artifact failure.
- Word: body paragraph (one-based), heading section, top-level table or table
  cell (one-based table/row/column). Heading sections include subordinate
  headings, paragraphs and tables, ending at the next equal/higher-level heading.
  A paragraph selector can refine a unique heading section. Stable HeadingN
  style IDs, paragraph/style outline levels and inherited styles recognize
  headings without depending on English display names.
- PowerPoint: slide, object, group descendants and table cell. `group_path`
  lists ancestor group IDs from outermost to innermost. Object IDs are resolved
  within the selected slide/group tree. Tables report row/column, and descendants
  report their actual object ID and group ancestry.

Missing/out-of-range positions return FAIL. Ambiguous duplicate heading/object
identities return NEEDS_REVIEW and null completion; no first match is selected
silently. Invalid configuration is rejected before artifact parsing as spec_gap.
Deterministic checks do not interpret arbitrary visual region strings.

CheckRecord.location and requested_location preserve the frozen request.
observed_locations records the actual text hits. Evidence retains both; a
cross-file issue may use its observed location for the legacy issue.location
field while keeping requested_location separately. Assessment validation binds
requested locations to the spec. Source files are never saved or modified.

Extraction admits at most 50,000 scope items / 2,000,000 characters; Excel scopes
also have a 50,000-cell rectangle limit before iteration. Exceeding the limit
returns NEEDS_REVIEW, never a pass based on truncated evidence. This is a bounded
content parser, not a general OCR, notes/header/footer or nested-Word-table
coverage claim. Unsupported channels need their own explicit checks.

PPT visible delivery, occlusion and true appearance remain T15 work. Formula
recalculation remains T13. Text found in an object does not prove that the object
is visible. T12 fixtures are real OOXML files generated by trusted local test
code; no model, Office process, renderer or server is invoked.
